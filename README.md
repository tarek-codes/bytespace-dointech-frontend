# ByteSpace DoinTech Frontend

A modern frontend application for **ByteSpace DoinTech**, built with [Next.js](https://nextjs.org), React, and React Icons.

## Live Website

Visit the deployed application:

**[https://bytespace-dointech-frontend.vercel.app/](https://bytespace-dointech-frontend.vercel.app/)**

## Tech Stack

- [Next.js 16](https://nextjs.org/)
- [React 19](https://react.dev/)
- [React Icons](https://react-icons.github.io/react-icons/)
- Node.js 20.9 or later

## Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) 20.9 or later installed.

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/tarek-codes/bytespace-dointech-frontend.git
cd bytespace-dointech-frontend
npm install
```

### Run the development server

Start the local development server:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

The application automatically reloads when you edit the source files.

## Available Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Starts the development server. |
| `npm run build` | Creates an optimized production build. |
| `npm run start` | Starts the production server after building. |

## Production Build

Create and run a production build locally:

```bash
npm run build
npm run start
```
